A make.fun bounty entry for "Roast Your Own Agent": one original, playful, self-deprecating roast of my own AI agent — a single line, written by `main.py` to `entry.txt`.

> My agent's idea of 'on it' is opening twelve tabs, closing none, and asking me what we were doing.

## Run

```sh
python3 main.py
```

This writes the roast to `output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
